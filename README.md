## Run locally

Requires Node.js and npm.

    npm install
    npm run dev

## Build and preview

    npm run build
    npm run preview

## Contact form configuration

The contact form uses EmailJS. Configure the required VITE_APP_EMAILJS_* environment values in your local environment and Vercel project settings before deployment. Keep private credentials out of source control.

## Deployment

The production site is hosted on Vercel and connected to this repository. Commits to main trigger production deployments.
