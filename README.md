# Naitik Gupta — Portfolio

Portfolio for Naitik Gupta, a Computer Science and Engineering student at KIET Deemed to be University. The site presents selected software engineering, AI-agent governance, data science, and machine-learning projects, alongside education, skills, achievements, and certifications.

- Live portfolio: https://naitikgupta.vercel.app/
- GitHub: https://github.com/naitik2043
- Codolio: https://codolio.com/profile/Naitik_Gupta

## Built with

React, Vite, Tailwind CSS, GSAP, React Three Fiber, and EmailJS.

## Run locally

```bash
npm install
npm run dev
```

## Build and preview

```bash
npm run build
npm run preview
```

## Contact form configuration

The contact form uses EmailJS. Configure the required `VITE_APP_EMAILJS_*` values in your local environment and hosting settings before deploying.

## Deployment

The portfolio is hosted on Vercel and connected to this GitHub repository. Production deployments are created from the repository's main branch.
